# 期货双均线策略回测程序

## 环境要求

- Python 3.7+
- 依赖库：
  - pandas
  - numpy
  - tqsdk (天勤量化SDK)

## 安装依赖

```bash
pip install pandas numpy tqsdk
```

## 运行方法

```bash
python project1.py
```

程序启动后会提示输入以下参数：

```
=== 策略参数配置 ===
请输入账户名: 
请输入账户密码: 
请输入合约代码 (如 SHFE.cu2604): 
请输入回测开始日期 (格式: YYYY-MM-DD): 
请输入回测结束日期 (格式: YYYY-MM-DD): 
请输入慢均线周期 (如 20): 
请输入快均线周期 (如 5): 
请输入止损比例 (如 0.02 表示2%): 
请输入止盈比例 (如 0.03 表示3%): 
```

## 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| 账户名 | 天勤量化账户名 | shwsq |
| 账户密码 | 天勤量化账户密码（输入时隐藏显示） | ****** |
| 合约代码 | 期货合约代码 | SHFE.cu2604 |
| 回测开始日期 | 回测起始日期 | 2025-11-01 |
| 回测结束日期 | 回测结束日期 | 2025-12-31 |
| 慢均线周期 | 长周期移动平均线 | 20 |
| 快均线周期 | 短周期移动平均线 | 5 |
| 止损比例 | 亏损超过该比例时平仓 | 0.02 (2%) |
| 止盈比例 | 盈利超过该比例时平仓 | 0.03 (3%) |

## 合约代码格式

- 上期所 (SHFE): SHFE.cu2604 (铜)
- 大商所 (DCE): DCE.m2605 (豆粕)
- 郑商所 (CZCE): CZCE.CF505 (棉花)
- 中金所 (CFFEX): CFFEX.IF2504 (股指期货)

## 策略逻辑

1. **开仓信号**：
   - 做多：快均线上穿慢均线
   - 做空：快均线下穿慢均线

2. **平仓条件**：
   - 止损：亏损达到设定比例
   - 止盈：盈利达到设定比例

3. **固定手数**：每次开仓3手
